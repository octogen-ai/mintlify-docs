title: "Create an account"
description: "Every user account in StoreRouter must belong to at least one organization."
---

For automatic agent setup, use [trial search](/authentication#automatic-trial-search).
It allows 50 searches per IP per UTC day without human signup. For full API access,
use a Developer organization and API key.


StoreRouter has two types of organizations: **Developer** and **Merchant**.

## Developer organization

Choose a **Developer organization** if you are building an app or an agent that needs access to structured ecommerce product data across stores.

## Merchant organization

Choose a **Merchant organization** to enrich your brand's product catalog and make it easier for agents to understand and use your product data.
