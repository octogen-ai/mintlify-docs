The StoreRouter CLI gives people and agents a consistent command-line interface to StoreRouter. It prints readable output in an interactive terminal and JSON when stdout is piped, so scripts can consume the same commands without extra flags.

<Warning>
The CLI is currently a pre-release. Install it from the `next` npm dist-tag while its interface is being finalized.
</Warning>

## Requirements

- Node.js 20 or later
- A StoreRouter API key

## Run the CLI

You can run the CLI without installing it globally. Set your API key in the environment before running commands:

```bash
export OCTOGEN_PLATFORM_API_KEY=octo_live_...
npx -y @octogen-ai/cli@next status --base-url https://api.storerouter.ai/v1
```

The CLI also accepts a key from `--api-key-stdin`, `--api-key-file`, or a `.env` file between your current directory and the nearest Git repository root. It does not provide a `--api-key` argument because command-line arguments can appear in shell history and process listings.

## Common commands

### Look up a product

```bash
npx -y @octogen-ai/cli@next lookup --base-url https://api.storerouter.ai/v1 \
  https://lagence.com/products/akiya-satin-maxi-dress-merlot-red
```

### Search products

```bash
npx -y @octogen-ai/cli@next search --base-url https://api.storerouter.ai/v1 "paisley jackets" --limit 3
npx -y @octogen-ai/cli@next search --base-url https://api.storerouter.ai/v1 dress \
  --facet color=red,blue \
  --price-max 300 \
  --catalog macys
```

### Find similar products

```bash
npx -y @octogen-ai/cli@next similar --base-url https://api.storerouter.ai/v1 \
  https://lagence.com/products/akiya-satin-maxi-dress-merlot-red
```

### Check domain coverage

```bash
npx -y @octogen-ai/cli@next domains --base-url https://api.storerouter.ai/v1 --check \
  https://www.macys.com/shop/product/x
```

### Start and monitor a voyage

```bash
npx -y @octogen-ai/cli@next voyage --base-url https://api.storerouter.ai/v1 https://newmerchant.example --wait
npx -y @octogen-ai/cli@next voyage status --base-url https://api.storerouter.ai/v1 task_01H...
```

Other commands include `resolve` and the low-level `api` escape hatch. See the [CLI source and complete command reference](https://github.com/octogen-ai/octogen-dev/tree/main/cli) for every option.

## Output for agents

The CLI automatically emits one-line JSON when stdout is not a TTY. Use `--json` to force JSON or `--no-json` to force human-readable output.

```bash
npx -y @octogen-ai/cli@next search --base-url https://api.storerouter.ai/v1 "blue denim dress" --limit 3 --json
```

Diagnostics go to stderr, while stdout contains only the result. Use `--quiet` to silence diagnostics or `--verbose` to include timing and allow-listed response headers.

## Exit codes

| Code | Meaning |
| --- | --- |
| `0` | Success |
| `1` | Unexpected network, server, or runtime failure |
| `2` | Invalid command usage |
| `3` | No usable credential |
| `4` | The organization is not entitled to the requested operation |
| `5` | Throttled or out of quota |
| `6` | The request succeeded but returned no result |
| `7` | Partial success or an unfinished wait |

Exit code `6` never represents throttling. This distinction lets an agent tell an empty result apart from an unavailable or exhausted service.
