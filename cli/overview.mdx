The StoreRouter CLI gives people and agents a consistent command-line interface to StoreRouter. It prints readable output in an interactive terminal and JSON when stdout is piped, so scripts can consume the same commands without extra flags.

<Warning>
The CLI is currently a pre-release. Install it from the `next` npm dist-tag while its interface is being finalized.
</Warning>

## Requirements

- Node.js 20 or later
- A StoreRouter API key

## Install or run the CLI

Install the prerelease package globally:

```bash
npm install -g @storerouter/cli@next
storerouter --version
```

Always specify `@next`: `latest` currently points to a reservation package.
The package provides two executable names, `storerouter` and the compatibility
alias `octogen`. When using npm exec or npx, select the executable explicitly:

```bash
npx --yes --package=@storerouter/cli@next storerouter --version
npm exec --yes --package=@storerouter/cli@next -- storerouter --version
```

If you installed `@octogen-ai/cli` globally, uninstall it before installing the
new package in the same npm prefix. Both packages own the `octogen` executable;
do not overwrite that link with `--force`. See the
[migration guide](https://github.com/octogen-ai/octogen-dev/blob/main/cli/MIGRATION.md)
for migration, credential precedence, and rollback steps.

## Configure credentials

You can run the CLI without installing it globally. Set your API key in the environment before running commands:

```bash
export STOREROUTER_API_KEY=octo_live_...
npm exec --yes --package=@storerouter/cli@next -- storerouter search "shirt" --limit 1
```

The default API is `https://api.storerouter.ai/v1`; normal commands do not need
`--base-url`. Existing API keys still work. `OCTOGEN_PLATFORM_API_KEY` remains a
compatibility fallback after `STOREROUTER_API_KEY`; `OCTO_API_KEY` is deprecated.

The CLI also accepts a key from `--api-key-stdin`, `--api-key-file`, or a `.env` file between your current directory and the nearest Git repository root. It does not provide a `--api-key` argument because command-line arguments can appear in shell history and process listings.

After a global install, use `storerouter` in place of the npm exec prefix below.
`parse` is an exact alias of `lookup`, including its JSON command name and exit codes.

## Common commands

### Look up a product

```bash
npm exec --yes --package=@storerouter/cli@next -- storerouter lookup \
  https://lagence.com/products/akiya-satin-maxi-dress-merlot-red
```

### Search products

```bash
npm exec --yes --package=@storerouter/cli@next -- storerouter search "paisley jackets" --limit 3
npm exec --yes --package=@storerouter/cli@next -- storerouter search dress \
  --facet color=red,blue \
  --price-max 300 \
  --catalog macys
```

### Find similar products

```bash
npm exec --yes --package=@storerouter/cli@next -- storerouter similar \
  https://lagence.com/products/akiya-satin-maxi-dress-merlot-red
```

Use the low-level `api` command for requests outside these examples. See the [complete command reference](https://github.com/octogen-ai/octogen-dev/blob/main/cli/REFERENCE.md) for every option.

## Output for agents

The CLI automatically emits one-line JSON when stdout is not a TTY. Use `--json` to force JSON or `--no-json` to force human-readable output.

```bash
npm exec --yes --package=@storerouter/cli@next -- storerouter search "blue denim dress" --limit 3 --json
```

Diagnostics go to stderr, while stdout contains only the result. Use `--quiet` to silence diagnostics or `--verbose` to include timing and allow-listed response headers.

## Exit codes

| Code | Meaning |
| --- | --- |
| `0` | Success |
| `1` | Unexpected network, server, or runtime failure |
| `2` | Invalid command usage |
| `3` | No usable credential |
| `4` | The organization is not entitled to the requested operation |
| `5` | Throttled or out of quota |
| `6` | The request succeeded but returned no result |
| `7` | Partial success or an unfinished wait |

Exit code `6` never represents throttling. This distinction lets an agent tell an empty result apart from an unavailable or exhausted service.
