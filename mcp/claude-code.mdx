Claude Code supports MCP servers over HTTP natively. Registering StoreRouter takes a single command, and the first tool call handles authentication automatically through a browser sign-in. No API keys, client IDs, or manual credential management are required.

<Steps>
  <Step title="Register the StoreRouter MCP server">
    Run the following command in your terminal:

    ```bash
    claude mcp add --transport http storerouter https://mcp.storerouter.ai/mcp
    ```

    This adds an entry named `storerouter` pointing at the StoreRouter MCP server. Claude Code stores the configuration locally and loads it at startup.
  </Step>

  <Step title="Sign in on first use">
    The first time your agent calls a StoreRouter tool, Claude Code opens a browser tab with the StoreRouter sign-in page. Complete the sign-in flow:

    1. Enter the email that belongs to your Developer organization.
    2. Authenticate using your organization's configured method (password, SSO, or magic link).
    3. If your account belongs to multiple organizations, select the Developer organization you want to act as.
    4. Consent to the requested scopes.

    After you complete sign-in, the browser redirects back to Claude Code. The resulting access token and refresh token are cached locally. Subsequent tool calls reuse the cached token without any browser interaction.

    <Note>
      Access tokens are valid for approximately five minutes. Claude Code refreshes them transparently in the background — you will not be prompted again unless your StoreRouter sign-in session expires.
    </Note>
  </Step>

  <Step title="Verify the server is registered">
    Confirm the entry appears in your MCP server list:

    ```bash
    claude mcp list
    ```

    You should see `storerouter` listed with the URL `https://mcp.storerouter.ai/mcp`.
  </Step>

  <Step title="Share the config with your team (optional)">
    To commit the MCP configuration to your repository so teammates pick it up automatically, re-run the registration command with the `--scope project` flag:

    ```bash
    claude mcp add --transport http --scope project storerouter https://mcp.storerouter.ai/mcp
    ```

    This writes the entry to `.mcp.json` at your repository root instead of your personal config. Each team member still signs in with their own StoreRouter account on first use — credentials are never stored in the project file.

    <Tip>
      Commit `.mcp.json` to version control. Anyone who clones the repository and runs Claude Code will have the StoreRouter server registered automatically.
    </Tip>
  </Step>
</Steps>

## What your agent can do

Once connected, your agent can use these tool groups:

- **Products**: `lookup_product` and `lookup_products` resolve product page URLs to full product records; `search_products` searches across all covered stores, with optional catalog, facet, price, store, and brand-style filters.
- **Taxonomy**: `taxonomy_tree` and `taxonomy_attribute` find the category and attribute filters that search accepts.
- **Brands**: `search_brands`, `similar_brands`, `brand_prefix`, `get_brand`, `browse_brand_products`, and `get_brand_top_categories`.
- **Stores**: `search_stores`, `similar_stores`, and `get_store` find retailers and describe what they sell.
- **BigQuery**: subscription tools for organizations with BigQuery access.

For arguments and error codes, see the [MCP overview](/mcp/overview#available-tools).
