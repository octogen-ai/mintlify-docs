Claude Desktop and claude.ai connect to remote MCP servers natively through custom connectors. You add StoreRouter once with its URL, and the connector is available in both apps for your Claude account. No config files, adapters, or API keys are required.

<Steps>
  <Step title="Open connector settings">
    In Claude Desktop or at [claude.ai](https://claude.ai), open **Settings** and select **Connectors**.

    <Note>
      On Claude Team and Enterprise plans, an organization Owner adds custom connectors under **Organization settings** → **Connectors**. Once an Owner has added StoreRouter, members connect to it from their own **Settings** → **Connectors** page.
    </Note>
  </Step>

  <Step title="Add StoreRouter as a custom connector">
    Click **Add custom connector** and enter:

    | Field | Value |
    | --- | --- |
    | Name | `StoreRouter` |
    | Remote MCP server URL | `https://mcp.storerouter.ai/mcp` |

    Leave the advanced OAuth client ID and secret fields empty. StoreRouter supports Dynamic Client Registration, so Claude registers itself automatically. Click **Add**.
  </Step>

  <Step title="Connect and sign in">
    Click **Connect** next to StoreRouter. Claude opens a browser tab with the StoreRouter sign-in page. Complete the sign-in flow:

    1. Enter the email that belongs to your Developer organization.
    2. Authenticate using your organization's configured method (password, SSO, or magic link).
    3. If your account belongs to multiple organizations, select the Developer organization you want to act as.
    4. Consent to the requested scopes.

    After sign-in, the browser redirects back to Claude and the connector shows as connected. Claude refreshes the tokens in the background, so you are not prompted again unless your StoreRouter sign-in session expires.
  </Step>

  <Step title="Turn on StoreRouter in a conversation">
    In a chat, open the tools menu in the message box and make sure **StoreRouter** is turned on. You can also choose which StoreRouter tools Claude may use without asking.

    Try a prompt such as "Find waterproof trail running shoes under $150."
  </Step>
</Steps>

## What your agent can do

Once connected, your agent can use these tool groups:

- **Products**: `lookup_product` and `lookup_products` resolve product page URLs to full product records; `search_products` searches across all covered stores, with optional catalog, facet, price, store, and brand-style filters.
- **Taxonomy**: `taxonomy_tree` and `taxonomy_attribute` find the category and attribute filters that search accepts.
- **Brands**: `search_brands`, `similar_brands`, `brand_prefix`, `get_brand`, `browse_brand_products`, and `get_brand_top_categories`.
- **Stores**: `search_stores`, `similar_stores`, and `get_store` find retailers and describe what they sell.
- **BigQuery**: subscription tools for organizations with BigQuery access.

For arguments and error codes, see the [MCP overview](/mcp/overview#available-tools).
