The StoreRouter Python SDK gives you an async, type-safe client for the StoreRouter commerce API. Install it from PyPI, point it at your `OCTOGEN_PLATFORM_API_KEY`, and you can search products by keyword and facet, find products similar to a source product, and look up any product by URL — all backed by Pydantic models so your IDE can autocomplete every field.

## Installation

<Steps>
  <Step title="Install the package">
    Requires Python 3.11 or later. Install `octogen-ai-sdk` from PyPI. This page documents version 0.11.0.

    ```bash
    pip install octogen-ai-sdk
    ```

    To work on the SDK itself, clone the public [`octogen-dev`](https://github.com/octogen-ai/octogen-dev) repository and run `uv sync` in `sdks/python`.
  </Step>
  <Step title="Set your API key">
    The client reads your key from the `OCTOGEN_PLATFORM_API_KEY` environment variable automatically.

    ```bash
    export OCTOGEN_PLATFORM_API_KEY=octo_live_...
    ```

    You can also pass `api_key=` directly to the constructor if you prefer to manage secrets yourself (see [Authentication](#authentication) below).
  </Step>
</Steps>

## Authentication

`OctogenClient` resolves your API key in this order:

1. The `api_key` constructor argument, if provided.
2. The `OCTOGEN_PLATFORM_API_KEY` environment variable.
3. The deprecated `OCTO_API_KEY` environment variable. Reading it raises a `DeprecationWarning` once, and support will be removed. Set `OCTOGEN_PLATFORM_API_KEY` instead.

If none of these is set, the constructor raises `MissingAPIKeyError` immediately — before any network request is made. Every request then sends the key as `Authorization: Bearer <api-key>`.

```python
from octogen_ai_sdk import OctogenClient

# From environment variable (recommended)
client = OctogenClient(base_url="https://api.storerouter.ai/v1")

# Explicit key
client = OctogenClient(api_key="octo_live_...", base_url="https://api.storerouter.ai/v1")
```

## Client constructor

These examples set the StoreRouter base URL explicitly, including when you use
an SDK release that predates the domain migration.

`OctogenClient` accepts the following keyword-only arguments:

| Parameter     | Type                              | Default                          | Description                                                     |
| ------------- | --------------------------------- | -------------------------------- | --------------------------------------------------------------- |
| `api_key`     | `str \| None`                     | `None` (reads `OCTOGEN_PLATFORM_API_KEY`) | Your Platform API key.                                          |
| `base_url`    | `str`                             | Set explicitly above             | Override the API base URL (useful for testing).                 |
| `timeout`     | `float \| httpx.Timeout`          | `30.0`                           | Request timeout in seconds, or a full `httpx.Timeout` object.  |
| `http_client` | `httpx.AsyncClient \| None`       | `None` (SDK creates one)         | Supply your own `httpx.AsyncClient` to reuse connections or configure proxies. |

### Using the client as an async context manager

Use `async with` to ensure the underlying HTTP connection pool is closed when you are done:

```python
import asyncio
from octogen_ai_sdk import OctogenClient

async def main() -> None:
    async with OctogenClient(base_url="https://api.storerouter.ai/v1") as client:
        results = await client.search_products(q="shirt", limit=1)
        print(results.items)

asyncio.run(main())
```

If you manage the client's lifetime yourself, call `await client.aclose()` when finished.

## Methods

### `lookup_product`

```python
async def lookup_product(
    url: str,
    *,
    resolution_mode: ProductLookupResolutionMode | str = "auto",
    on_demand_cache_policy: ProductLookupCachePolicy | str = "prefer_cache",
) -> MerchantProductUrlLookupResponse
```

Resolves a product page URL from StoreRouter's index or with on-demand product resolution. Set `resolution_mode="index_only"` when your integration requires indexed identity and catalog context.

```python
result = await client.lookup_product(
    "https://example.com/products/blue-linen-dress",
    resolution_mode="auto",
)
if result.source == "indexed":
    print(result.catalog_key, result.product.uuid)
else:
    print(result.product.title, result.product.currency)
```

**Returns:** `MerchantProductUrlLookupResponse`

| Field                  | Type                  | Description                               |
| ---------------------- | --------------------- | ----------------------------------------- |
| `source`               | `Literal["indexed", "on_demand"]` | Source that produced the result. |
| `catalog_key`          | `str \| None`         | Indexed catalog, or `None` on demand. |
| `catalog_display_name` | `str \| None`         | Indexed catalog name, or `None` on demand. |
| `product`              | `MerchantProductView` | Full or partial-safe product view. |
| `resolution`           | `ProductResolutionMetadata \| None` | On-demand completeness and evidence. |

### `search_products`

```python
async def search_products(
    *,
    q: str | None = None,
    understand: bool | None = None,
    facets: Sequence[Facet | dict] | None = None,
    exclude_facets: Sequence[Facet | dict] | None = None,
    omit_generated_facets: Sequence[str] | None = None,
    price_min: float | None = None,
    price_max: float | None = None,
    brand_quality_min: float | None = None,
    brand_quality_max: float | None = None,
    similar_to_brands: Sequence[str] | None = None,
    catalogs: Sequence[str] | None = None,
    limit: int = 50,
    cursor: str | None = None,
    relax: bool | None = None,
    debug: bool | None = None,
) -> ProgrammaticProductSearchPage
```

Searches every catalog your key can access, or only the catalogs in `catalogs`. Each keyword controls one thing and is sent under the same wire name. See [`POST /products/search`](/api-reference/search-products) for the full field semantics.

| Parameter               | Type                              | Default | Description |
| ----------------------- | --------------------------------- | ------- | ----------- |
| `q`                     | `str \| None`                     | `None`  | Free-text query, understood by default. Omit to browse by filters alone. |
| `understand`            | `bool \| None`                    | `None`  | `False` matches `q` as written and filters only by what you send. Requires `q`. The server default is `True`. |
| `facets`                | `Sequence[SearchFacet \| Facet \| dict] \| None` | `None`  | Filters a product must match. Replaces any understood facet of the same name. A `SearchFacet` (or dict) with `relaxable=True` may be dropped by `relax`; any other facet never is. See [Faceted search](#faceted-search). |
| `exclude_facets`        | `Sequence[Facet \| dict] \| None` | `None`  | Filters a product must not match. |
| `omit_generated_facets` | `Sequence[str] \| None`           | `None`  | Names of understood facets to drop. Use the names `effective_query` reports. Requires an understood `q`. |
| `price_min`             | `float \| None`                   | `None`  | Inclusive minimum price, at least `0`. |
| `price_max`             | `float \| None`                   | `None`  | Inclusive maximum price, at least `0`. |
| `brand_quality_min`     | `float \| None`                   | `None`  | Inclusive minimum brand quality, from `1` (very poor) to `6` (exceptional). |
| `brand_quality_max`     | `float \| None`                   | `None`  | Inclusive maximum brand quality, from `1` to `6`. |
| `similar_to_brands`     | `Sequence[str] \| None`           | `None`  | 1 to 10 brand names whose style to favor. Ranks, does not filter. |
| `catalogs`              | `Sequence[str] \| None`           | `None`  | 1 to 500 catalog keys. Omit to search every catalog your key can access. |
| `limit`                 | `int`                             | `50`    | Number of results per page. Must be between 1 and 100. |
| `cursor`                | `str \| None`                     | `None`  | The `next_cursor` from the previous page, passed back verbatim with the same arguments. |
| `relax`                 | `bool \| None`                    | `None`  | Drop understood filters, and facets you marked `relaxable`, in stages when `q` returns nothing. Requires `q`, and either `understand` left on or at least one relaxable facet. |
| `debug`                 | `bool \| None`                    | `None`  | Include `effective_query`, the search that actually ran. |

**Returns:** `ProgrammaticProductSearchPage`, a `MerchantProductListPage` subclass.

| Field             | Type                                             | Description |
| ----------------- | ------------------------------------------------ | ----------- |
| `items`           | `list[MerchantProductListItem]`                  | Products on this page. |
| `next_cursor`     | `str \| None`                                    | Pass as `cursor` in your next call to get the next page. `None` means no more results. |
| `request_id`      | `str \| None`                                    | Server-generated ID for this request. |
| `effective_query` | `ProgrammaticProductSearchEffectiveQuery \| None` | Present only when `debug` is `True`. Reports `text`, `understood`, `facets` and `exclude_facets` (each facet with `source` `"caller"` or `"generated"`, and `relaxable=True` on a facet you marked), the price and brand-quality bounds, `similar_to_brands`, `catalogs`, and `relaxation` (`rounds`, `dropped_facets`, `declined_rounds`). It is a report, not a request fragment. |

Each `MerchantProductListItem` includes `uuid`, `catalog_key`, `product_url`, `title`, `brand`, `current_price`, `original_price`, `primary_image`, `images`, `rating`, `is_active`, optional match scores, and `updated_at`. It also carries the deprecated `image_url`.

`primary_image` and each entry in `images` are [`MerchantProductImageMetadataView`](/api-reference/models/product#merchantproductimagemetadataview) models with `url`, `cdn_url`, `width`, `height`, `size_bytes`, and `mime_type`. Prefer the hosted copy and fall back to the merchant URL:

```python
image = product.primary_image
src = (image.cdn_url or image.url) if image else None
```

```python
page = await client.search_products(
    q="black hoodie",
    catalogs=["warrenlotas"],  # omit to search every catalog your key can access
    facets=[{"name": "color", "values": ["black"]}],
    exclude_facets=[{"name": "brand_name", "values": ["acme"]}],
    price_min=50,
    price_max=300,
    brand_quality_min=4,
    relax=True,
    debug=True,
)
if page.effective_query is not None:
    for facet in page.effective_query.facets or []:
        print(facet.name, facet.values, facet.source)  # "caller" | "generated"
```

#### Local validation

The SDK checks the contradictions the API would refuse and raises `pydantic.ValidationError` before sending a request:

- `understand=False`, `relax=True`, or a non-empty `omit_generated_facets` without `q`. `omit_generated_facets` also requires `understand` to stay on, and so does `relax=True` unless at least one facet is sent with `relaxable=True`.
- A facet name repeated within `facets` or `exclude_facets`, or a name in both `facets` and `omit_generated_facets`.
- More than 50 entries in `facets`, `exclude_facets`, or `omit_generated_facets`.
- A negative price or `price_min > price_max`.
- Brand quality outside 1–6, or `brand_quality_min > brand_quality_max`.
- `similar_to_brands` that is empty, has more than 10 names, or has a blank name.

An empty `catalogs` list or a blank key raises `ValueError`, and a bare string raises `TypeError`. The server remains the source of truth for everything else, such as unknown facet names.

#### Removed in 0.5.0

These keywords were deprecated in 0.4.0 and are gone in 0.5.0, because the API now rejects them with a `422`. Passing one to `search_products` raises `TypeError`.

| Removed | Use instead |
| --- | --- |
| `catalog="macys"` | `catalogs=["macys"]` |
| `text_search_query={...}` and the `TextSearchQuery` model | `q` with `understand=False`, your filters in `facets` and `exclude_facets` (formerly `exclusion_facets`), and the bounds and brands as top-level `price_min`, `price_max`, `brand_quality_min`, `brand_quality_max`, and `similar_to_brands` |

```python
# 0.4.0
await client.search_products(catalog="macys", q="linen dress")

# 0.5.0
await client.search_products(catalogs=["macys"], q="linen dress")
await client.search_products(
    q="linen dress",
    understand=False,
    facets=[{"name": "color_family", "values": ["blue"]}],
    exclude_facets=[{"name": "brand_name", "values": ["acme"]}],
    price_max=200,
)
```

`text_search_query`'s retrieval tuning (`search_id`, `ranking_text`, embedding columns, similarity weights, `search_after`, `browse_menu_uuid`, `compact_mode`) has no replacement on `/v1` search.

### `more_like_this_products`

```python
async def more_like_this_products(
    *,
    source_url: str | None = None,
    source_uuid: str | None = None,
    catalogs: Sequence[str] | None = None,
    facets: Sequence[Facet | dict] | None = None,
    exclude_facets: Sequence[Facet | dict] | None = None,
    price_min: float | None = None,
    price_max: float | None = None,
    brand_quality_min: float | None = None,
    brand_quality_max: float | None = None,
    price_preference: PricePreference | str = PricePreference.ANY,
    relax: bool | None = None,
    cursor: str | None = None,
    limit: int = 12,
    debug: bool = False,
) -> ProgrammaticMoreLikeThisResponse
```

Finds products similar to a source product URL or UUID. Provide exactly one of `source_url` or `source_uuid`. Omit `catalogs` to search all active crawled catalogs, or pass 1–100 catalog keys to keep the results within those catalogs.

```python
page = await client.more_like_this_products(
    source_url="https://warrenlotas.com/products/black-hoodie",
    catalogs=["warrenlotas"],
    price_preference="any",
    limit=12,
)
```

| Parameter          | Type                               | Default | Description |
| ------------------ | ---------------------------------- | ------- | ----------- |
| `source_url`       | `str \| None`                      | `None`  | Canonical product URL to use as the source. |
| `source_uuid`      | `str \| None`                      | `None`  | Indexed product UUID to use as the source. |
| `catalogs`         | `Sequence[str] \| None`            | `None`  | Optional allowlist of 1–100 catalog keys. Omit to search all active crawled catalogs. |
| `facets`           | `Sequence[Facet \| dict] \| None`  | `None`  | Filters a product must match. A facet you send replaces the generated facet of the same name and is never relaxed. Replaces `include_facets` (removed in 0.8.0). |
| `exclude_facets`   | `Sequence[Facet \| dict] \| None`  | `None`  | Filters a product must not match. |
| `price_min` / `price_max` | `float \| None`             | `None`  | Inclusive price bounds. Never relaxed. |
| `brand_quality_min` / `brand_quality_max` | `float \| None` | `None` | Inclusive brand-quality bounds, 1 to 6. Never relaxed. |
| `price_preference` | `PricePreference \| str`           | `any`   | `lower`, `any`, or `higher` relative to the source product. |
| `relax`            | `bool \| None`                     | `None`  | Omitted unless set; the server defaults it to `True`. Retries a short page 1 with generated facets dropped, never yours. See [Relaxation](/guides/more-like-this#relaxation). |
| `cursor`           | `str \| None`                      | `None`  | Pagination cursor from a previous response's `next_cursor`. |
| `limit`            | `int`                              | `12`    | Number of results per page. Must be between 1 and 100. |
| `debug`            | `bool`                             | `False` | Include the public `effective_query` used for retrieval. |

**Returns:** `ProgrammaticMoreLikeThisResponse`

| Field             | Type                                      | Description |
| ----------------- | ----------------------------------------- | ----------- |
| `source`          | `ProgrammaticMoreLikeThisSourceResponse`  | Source product identity. |
| `items`           | `list[MerchantProductListItem]`           | Similar products on this page. |
| `next_cursor`     | `str \| None`                             | Pass as `cursor` in your next call to get the next page. |
| `effective_query` | `ProgrammaticMoreLikeThisEffectiveQuery \| None` | Present only when `debug` is `True`. With `relax` on, `relaxation` reports `rounds`, `declined_rounds`, and `dropped_facets`. |

## Complete example

The following example searches all active crawled catalogs for women's linen dresses and prints each result with its brand and price:

```python
import asyncio
from pprint import pformat

from octogen_ai_sdk import OctogenAPIError, OctogenClient


async def main() -> None:
    try:
        async with OctogenClient(base_url="https://api.storerouter.ai/v1") as client:
            results = await client.search_products(
                q="women's linen summer dresses",
                limit=5,
            )

            print("Catalog scope: all active crawled catalogs")
            for product in results.items:
                brand = product.brand.name if product.brand else "Unknown brand"
                price = (
                    f"${product.current_price:.2f}"
                    if product.current_price is not None
                    else "Price unavailable"
                )
                title = product.title or "Untitled product"
                print(f"- {title} | {brand} | {price}")
                print(f"  {product.product_url}")
    except OctogenAPIError as exc:
        print(f"StoreRouter API error: status={exc.status_code}")
        print(pformat(exc.detail))
        raise


if __name__ == "__main__":
    asyncio.run(main())
```

## Faceted search

Use `Facet` objects to filter by brand, gender, color, category, and other attributes. Pass a list of facets to the `facets` parameter of `search_products`.

```python
from octogen_ai_sdk import Facet, FacetName, OctogenClient

async with OctogenClient(base_url="https://api.storerouter.ai/v1") as client:
    results = await client.search_products(
        q="summer dress",
        facets=[
            Facet(name=FacetName.GENDER, values=["female"]),
            Facet(name=FacetName.COLOR_FAMILY, values=["blue", "green"]),
        ],
        price_max=150.0,
        limit=20,
    )
    for product in results.items:
        print(product.title, product.product_url)
```

You can also pass plain dicts instead of `Facet` instances — the SDK coerces them automatically:

```python
facets=[
    {"name": "gender", "values": ["female"]},
    {"name": "color_family", "values": ["blue", "green"]},
]
```

<Tip>
  `FacetName` is a `StrEnum` with constants for all built-in facet fields: `BRAND_NAME`, `GENDER`, `AGE_GROUPS`, `COLOR`, `COLOR_FAMILY`, `IS_ACTIVEWEAR`, `PRODUCT_TYPE`, `CATEGORY_PATH_DEPTH_0` through `CATEGORY_PATH_DEPTH_6`, and more. You can also pass a taxonomy attribute handle, such as `fit`, as a plain string. Use the bare handle: `attribute_facets.fit` is rejected. Facet values are canonical lowercase handles. See [Facet names](/api-reference/search-products#facet-names).
</Tip>

## Pagination

When `next_cursor` is not `None` in a response, pass it back verbatim as `cursor`, with the same other arguments, to retrieve the following page. A cursor the API cannot use returns `400` with `detail` `"invalid cursor"`; restart from page 1 without `cursor`. A product can repeat across pages, so de-duplicate by `uuid`.

```python
cursor = None
while True:
    page = await client.search_products(
        q="linen dress",
        cursor=cursor,
        limit=50,
    )
    for product in page.items:
        print(product.title)
    if page.next_cursor is None:
        break
    cursor = page.next_cursor
```

## Error handling

All SDK errors inherit from `OctogenError`. HTTP errors inherit from `OctogenAPIError`, which exposes `status_code`, `detail`, and `response` attributes.

<AccordionGroup>
  <Accordion title="OctogenAuthenticationError — 401">
    Raised when your API key is missing, malformed, or has been revoked. Check that `OCTOGEN_PLATFORM_API_KEY` is set correctly and that the key is still active in StoreRouter Platform.
  </Accordion>
  <Accordion title="OctogenForbiddenError — 403">
    Raised when a valid key attempts an action it is not authorized for — for example, accessing a catalog that has not been granted to your organization.
  </Accordion>
  <Accordion title="OctogenNotFoundError — 404">
    Raised when a catalog or product URL cannot be found. For `lookup_product`, verify the URL belongs to a catalog your key can access.
  </Accordion>
  <Accordion title="OctogenValidationError — 422">
    Raised when the API rejects a request due to invalid parameters. The `detail` attribute contains the validation error list from the API. `search_products` catches many invalid combinations locally and raises `pydantic.ValidationError` before sending a request.
  </Accordion>
  <Accordion title="OctogenConnectionError">
    Raised when the SDK cannot reach the API — for example, due to a network timeout or DNS failure. Does not have a `status_code`.
  </Accordion>
</AccordionGroup>

Catch the base `OctogenAPIError` to handle all HTTP errors in one place:

```python
from octogen_ai_sdk import (
    OctogenAPIError,
    OctogenAuthenticationError,
    OctogenConnectionError,
)

try:
    results = await client.search_products(q="dress")
except OctogenAuthenticationError:
    print("Check your OCTOGEN_PLATFORM_API_KEY.")
except OctogenAPIError as exc:
    print(f"API error {exc.status_code}: {exc.detail}")
except OctogenConnectionError as exc:
    print(f"Network error: {exc}")
```

<Warning>
  `MissingAPIKeyError` is raised by the constructor, not by a network call. It will surface at client creation time if neither `api_key` nor an API key environment variable is present.
</Warning>

## BigQuery subscribe (optional)

If StoreRouter shares a catalog with you over [BigQuery Analytics Hub](https://cloud.google.com/bigquery/docs/analytics-hub-introduction), the SDK can subscribe to the listing and create a linked dataset in your own Google Cloud project, so you can query the catalog with SQL. See the [Subscribe to a catalog in BigQuery](/guides/bigquery-subscribe) guide for the full walkthrough.

This helper uses your **Google Cloud** Application Default Credentials — not your `OCTOGEN_PLATFORM_API_KEY` — so it lives behind an optional `bigquery` extra:

```bash
pip install "octogen-ai-sdk[bigquery]"
gcloud auth application-default login
```

This installs the `octogen-bq-subscribe` CLI (dry-run by default; `--apply` to subscribe) and the `octogen-bq-autosubscribe` cron helper for keeping linked datasets current as new listings become available:

```bash
octogen-bq-subscribe --listing <listing-resource> --project my-gcp-project --apply
```

### `subscribe_to_listing`

```python
def subscribe_to_listing(
    *,
    listing_resource: str,
    destination_project: str,
    destination_dataset_id: str | None = None,
    location: str | None = None,
    friendly_name: str | None = None,
    credentials: Any = None,
) -> BigQuerySubscriptionResult
```

A **synchronous** function (unlike the async `OctogenClient`). Idempotent — an existing subscription to the same listing in `destination_project` is returned as-is.

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `listing_resource` | `str` | — | Listing resource name from the Platform UI BigQuery sharing page or MCP `list_bigquery_listing_resources` tool. |
| `destination_project` | `str` | — | Destination GCP project for the linked dataset (must be yours). |
| `destination_dataset_id` | `str \| None` | `octogen_<listing-id>` | Linked dataset id. |
| `location` | `str \| None` | The listing's location | BigQuery dataset location. |
| `friendly_name` | `str \| None` | `None` | Linked dataset display name. |
| `credentials` | `google.auth.credentials.Credentials \| None` | `None` (uses ADC) | Explicit Google credentials, if you don't want to use ADC. |

**Returns:** `BigQuerySubscriptionResult` with `listing_resource`, `linked_project`, `linked_dataset`, `state`, `already_subscribed`, `subscription_name`, and a ready-to-run `sample_query`.

```python
from octogen_ai_sdk import subscribe_to_listing

result = subscribe_to_listing(
    listing_resource="projects/octogen-prod/locations/us/dataExchanges/oneoff/listings/farfetch",
    destination_project="my-gcp-project",
)
print(result.linked_dataset, result.state)
```

<Note>
  Two BigQuery error types extend `OctogenError`: `OctogenBigQueryError` (base) and `OctogenBigQueryAccessPendingError`, raised when StoreRouter's IAM grant on the listing hasn't propagated yet. Because the grant is asynchronous, catch the access-pending error and retry after a few minutes.
</Note>
