The StoreRouter search endpoint lets you find products across every catalog your key can access using free-text queries, structured facet filters, and price range constraints — in any combination. Omit `catalogs` to search every catalog your key can access. Send `catalogs` with a list of catalog keys when you want to restrict search to those catalogs.

## How search works

When you call `POST /v1/products/search`, StoreRouter runs the query against every catalog your key can access, or only the catalogs listed in `catalogs`. Each field controls one thing, and a request that combines fields in a contradictory way returns a `422`. See the [validation rules](/api-reference/search-products#validation-rules).

By default, StoreRouter understands `q`: it rewrites the text for retrieval and derives filters such as category, gender, color, brand, and price from it. See [Control query understanding](#control-query-understanding) to inspect or override those derived filters.

The response returns a page of matching items and an opaque `nextCursor` you use to fetch subsequent pages. Each item in `items` is a lightweight product record — enough to render a card or feed a ranking model — while the full canonical record is available via [product lookup](/guides/product-lookup).

If you already have a source product and want similar items, use [More Like This](/guides/more-like-this) instead of inventing a keyword query.

## Basic keyword search

Pass a free-text string as `q` to search by keyword. Omit `q` entirely to browse without any keyword filter.

<CodeGroup>

```bash curl
curl -sS https://api.storerouter.ai/v1/products/search \
  -H "Authorization: Bearer $OCTOGEN_PLATFORM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "q": "black hoodie",
    "limit": 10
  }'
```

```python python
import asyncio
from octogen_ai_sdk import OctogenClient

async def main() -> None:
    async with OctogenClient(base_url="https://api.storerouter.ai/v1") as client:
        results = await client.search_products(
            q="black hoodie",
            limit=10,
        )
        for product in results.items:
            print(product.title, product.product_url)

asyncio.run(main())
```

```typescript typescript
import { OctogenClient } from "@octogen-ai/sdk";

const client = new OctogenClient({ baseUrl: "https://api.storerouter.ai/v1" });
const results = await client.searchProducts({
  q: "black hoodie",
  limit: 10,
});

for (const product of results.items) {
  console.log(product.title, product.productUrl);
}
```

</CodeGroup>

## Faceted filtering

Facets let you filter by structured product attributes. Each facet is an object with a `name` and a `values` array. You can apply multiple facets in a single request — the filters are combined with AND logic, so each additional facet narrows the result set. A product matches a facet when it has any of the listed values. Each facet name may appear only once in `facets`.

Commonly used facet names:

| Facet name | Description |
| --- | --- |
| `brand_name` | Canonical brand name |
| `brand_slug` | URL-safe brand identifier (e.g. `"warren-lotas"`) |
| `product_type` | Product category type (e.g. `"hoodie"`, `"sneaker"`) |
| `gender` | `male`, `female`, or `unisex` |
| `age_groups` | `infant`, `toddler`, `kids`, or `adult` |
| `color` | Specific color label (e.g. `"black"`, `"vintage white"`) |
| `color_family` | Broad color family (e.g. `"black"`, `"blue"`, `"green"`) |
| `category_path.depth_0` – `depth_6` | Hierarchical category path at a given depth |

Facet values are canonical lowercase handles and may contain spaces. You can also filter on taxonomy attribute handles by their bare name, such as `fit`. The `attribute_facets.` prefix is not accepted, except for `attribute_facets.color`. See [Facet names](/api-reference/search-products#facet-names) for the full list.

To remove products instead, send the same facet shape in `exclude_facets`. For example, `"exclude_facets": [{"name": "brand_name", "values": ["acme"]}]` drops one brand.

<CodeGroup>

```bash curl
curl -sS https://api.storerouter.ai/v1/products/search \
  -H "Authorization: Bearer $OCTOGEN_PLATFORM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "facets": [
      {"name": "color", "values": ["black"]},
      {"name": "gender", "values": ["male"]},
      {"name": "category_path.depth_0", "values": ["tops"]}
    ],
    "limit": 25
  }'
```

```python python
import asyncio
from octogen_ai_sdk import OctogenClient
from octogen_ai_sdk.models import Facet, FacetName

async def main() -> None:
    async with OctogenClient(base_url="https://api.storerouter.ai/v1") as client:
        results = await client.search_products(
            facets=[
                Facet(name=FacetName.COLOR, values=["black"]),
                Facet(name=FacetName.GENDER, values=["male"]),
                Facet(name=FacetName.CATEGORY_PATH_DEPTH_0, values=["tops"]),
            ],
            limit=25,
        )
        for product in results.items:
            price = f"${product.current_price:.2f}" if product.current_price else "N/A"
            print(f"{product.title} — {price}")

asyncio.run(main())
```

```typescript typescript
import { OctogenClient, FacetName } from "@octogen-ai/sdk";

const client = new OctogenClient({ baseUrl: "https://api.storerouter.ai/v1" });
const results = await client.searchProducts({
  facets: [
    { name: FacetName.COLOR, values: ["black"] },
    { name: FacetName.GENDER, values: ["male"] },
    { name: FacetName.CATEGORY_PATH_DEPTH_0, values: ["tops"] },
  ],
  limit: 25,
});

for (const product of results.items) {
  const price = product.currentPrice != null ? `$${product.currentPrice.toFixed(2)}` : "N/A";
  console.log(`${product.title ?? "Untitled"} — ${price}`);
}
```

</CodeGroup>

## Price range filtering

Use `price_min` and `price_max` to restrict results to a price range. Both bounds are inclusive. You can use either bound on its own.

<CodeGroup>

```bash curl
curl -sS https://api.storerouter.ai/v1/products/search \
  -H "Authorization: Bearer $OCTOGEN_PLATFORM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "q": "hoodie",
    "price_min": 100,
    "price_max": 300
  }'
```

```python python
import asyncio
from octogen_ai_sdk import OctogenClient

async def main() -> None:
    async with OctogenClient(base_url="https://api.storerouter.ai/v1") as client:
        results = await client.search_products(
            q="hoodie",
            price_min=100,
            price_max=300,
        )
        for product in results.items:
            print(product.title, product.current_price)

asyncio.run(main())
```

```typescript typescript
import { OctogenClient } from "@octogen-ai/sdk";

const client = new OctogenClient({ baseUrl: "https://api.storerouter.ai/v1" });
const results = await client.searchProducts({
  q: "hoodie",
  priceMin: 100,
  priceMax: 300,
});

for (const product of results.items) {
  console.log(product.title, product.currentPrice);
}
```

</CodeGroup>

## Combined example: keyword, facets, and price range

You can combine `q`, `facets`, and price filters in a single request. All active filters are applied together.

<CodeGroup>

```bash curl
curl -sS https://api.storerouter.ai/v1/products/search \
  -H "Authorization: Bearer $OCTOGEN_PLATFORM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "q": "graphic tee",
    "facets": [
      {"name": "color_family", "values": ["black"]},
      {"name": "gender", "values": ["unisex"]}
    ],
    "price_min": 50,
    "price_max": 200,
    "limit": 20
  }'
```

```python python
import asyncio
from octogen_ai_sdk import OctogenClient
from octogen_ai_sdk.models import Facet, FacetName

async def main() -> None:
    async with OctogenClient(base_url="https://api.storerouter.ai/v1") as client:
        results = await client.search_products(
            q="graphic tee",
            facets=[
                Facet(name=FacetName.COLOR_FAMILY, values=["black"]),
                Facet(name=FacetName.GENDER, values=["unisex"]),
            ],
            price_min=50,
            price_max=200,
            limit=20,
        )
        print(f"Found {len(results.items)} products")
        for product in results.items:
            brand = product.brand.name if product.brand else "Unknown"
            print(f"- {product.title} | {brand} | ${product.current_price}")

asyncio.run(main())
```

```typescript typescript
import { OctogenClient, FacetName } from "@octogen-ai/sdk";

const client = new OctogenClient({ baseUrl: "https://api.storerouter.ai/v1" });
const results = await client.searchProducts({
  q: "graphic tee",
  facets: [
    { name: FacetName.COLOR_FAMILY, values: ["black"] },
    { name: FacetName.GENDER, values: ["unisex"] },
  ],
  priceMin: 50,
  priceMax: 200,
  limit: 20,
});

console.log(`Found ${results.items.length} products`);
for (const product of results.items) {
  const brand = product.brand?.name ?? "Unknown";
  console.log(`- ${product.title} | ${brand} | $${product.currentPrice}`);
}
```

</CodeGroup>

## Restrict search to catalogs

Send `catalogs` with 1 to 500 catalog keys to search only those catalogs. Keys your key cannot access match nothing. Omit `catalogs` to search every catalog your key can access.

<CodeGroup>

```bash curl
curl -sS https://api.storerouter.ai/v1/products/search \
  -H "Authorization: Bearer $OCTOGEN_PLATFORM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "q": "black hoodie",
    "catalogs": ["warrenlotas"],
    "limit": 10
  }'
```

```python python
results = await client.search_products(
    q="black hoodie",
    catalogs=["warrenlotas"],
    limit=10,
)
```

```typescript typescript
const results = await client.searchProducts({
  q: "black hoodie",
  catalogs: ["warrenlotas"],
  limit: 10,
});
```

</CodeGroup>

<Note>
  The single-valued `catalog` field was removed and now returns a `422`. Send `catalogs: ["<key>"]` instead.
</Note>

## Control query understanding

By default, StoreRouter understands `q` and derives filters from it. These fields let you inspect and adjust that behavior:

- `debug: true` adds `effectiveQuery` to the response. It reports the text, facets, and bounds that actually ran. Each facet carries `source: "caller"` for one you sent, or `source: "generated"` for one understood from `q`.
- A facet you send in `facets` replaces any understood facet of the same name.
- `omit_generated_facets` drops an understood facet that is wrong when you have no value of your own for it. Use the names `effectiveQuery` reports.
- `understand: false` matches `q` as written and filters only by what you send.
- `relax: true` drops understood filters in stages when an understood `q` returns nothing. Facets you send are never dropped.
- `brand_quality_min` and `brand_quality_max` bound brand quality from `1` (very poor) to `6` (exceptional). `similar_to_brands` ranks results toward the style of up to 10 brands without filtering.

<CodeGroup>

```bash curl
curl -sS https://api.storerouter.ai/v1/products/search \
  -H "Authorization: Bearer $OCTOGEN_PLATFORM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "q": "black hoodie",
    "omit_generated_facets": ["fit"],
    "relax": true,
    "debug": true
  }'
```

```python python
page = await client.search_products(
    q="black hoodie",
    omit_generated_facets=["fit"],
    relax=True,
    debug=True,
)
if page.effective_query is not None:
    for facet in page.effective_query.facets or []:
        print(facet.name, facet.values, facet.source)
```

```typescript typescript
const page = await client.searchProducts({
  q: "black hoodie",
  omitGeneratedFacets: ["fit"],
  relax: true,
  debug: true,
});
for (const facet of page.effectiveQuery?.facets ?? []) {
  console.log(facet.name, facet.values, facet.source);
}
```

</CodeGroup>

<Warning>
  `effectiveQuery` is a report, not a request fragment. Don't send it back as a request body: understood facets of one name can AND together, which a request cannot express.
</Warning>

To match text exactly as written with your own filters, send `q` with `understand: false`. This replaces the removed `text_search_query` field:

```json
{
  "q": "linen dress",
  "understand": false,
  "facets": [{"name": "color_family", "values": ["blue"]}],
  "exclude_facets": [{"name": "brand_name", "values": ["acme"]}],
  "price_max": 200
}
```

## Understanding results

Each search response contains these top-level fields:

| Field | Type | Description |
| --- | --- | --- |
| `items` | array | List of product records matching the query. |
| `nextCursor` | string \| null | Pagination cursor. Non-null means more pages are available. See [Pagination](/guides/pagination). |
| `requestId` | string | Server-generated ID for this request. |
| `effectiveQuery` | object \| null | The search that actually ran. Present only with `debug: true`. |

Each item in `items` contains the following fields:

| Field | Type | Description |
| --- | --- | --- |
| `uuid` | string | Stable unique identifier for the product. |
| `catalogKey` | string \| null | Catalog that supplied the product. |
| `productUrl` | string | Canonical URL on the retailer's site. |
| `title` | string \| null | Product display name. |
| `brand` | object \| null | Brand with `name` and optional `slug`, `url`, `description`. |
| `currentPrice` | number \| null | Current selling price. |
| `originalPrice` | number \| null | Pre-discount price, if available. |
| `primaryImage` | object \| null | The product's display [image object](/api-reference/models/product#merchantproductimagemetadataview). Read `cdnUrl` and fall back to `url`. |
| `images` | object[] | All product [image objects](/api-reference/models/product#merchantproductimagemetadataview) in display order. |
| `imageUrl` | string \| null | Deprecated. The primary image's hosted CDN URL. Read `primaryImage` instead. |
| `rating` | object \| null | Average rating and review count, if available. |
| `isActive` | boolean | Whether the product is active in the current index. |
| `updatedAt` | string \| null | ISO 8601 timestamp of the last catalog update. |

<Tip>
  To get the full product record with fields like `description`, `sizes`, `colors`, `variants`, `identifiers`, and `enrichment`, use [product lookup](/guides/product-lookup) with the `productUrl` from a search result.
</Tip>
