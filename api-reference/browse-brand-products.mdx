---
title: "Browse brand products"
description: "Page through a brand's active products within your authorized catalog scope."
---

Use `GET /v1/brands/{brand}/products` for a stable brand product grid. Products are ordered by ascending UUID, including the first page. Use [Product Search](/api-reference/search-products) for interactive relevance search and additional filters.

```bash
curl 'https://api.storerouter.ai/v1/brands/allbirds/products?limit=24&offset=0' \
  -H "Authorization: Bearer $STOREROUTER_API_KEY"
```

URL-encode a brand slug or case-insensitive name as `brand`. `limit` is 1–100, default 24. `offset` is 0–11976 inclusive, default 0. An offset above 11976 returns `422`.

The `BrandProductsPage` contains `brandName`, `brandSlug`, `products`, `total`, `limit`, `offset`, `hasMore`, and nullable `nextOffset`. Products use the same `MerchantProductListItem` shape as Product Search. The source count and page both respect your authorized catalog scope. A known brand with no accessible products returns a successful empty page; an unknown brand returns `404`.

## Follow the server's continuation

Request the next page using `nextOffset`. Stop when it is null; `hasMore` is exactly `nextOffset != null`.

The server advances by source page size, including malformed rows omitted during public projection. A short or empty `products` list can still have a non-null `nextOffset`. Do not calculate continuation from `products.length` or treat an empty projected page as a missing brand. `total` counts source rows before projection, so it can exceed the number of usable products returned.

At 24 rows per page, page 499 has offset 11952 and can advance to 11976. Page 500 has offset 11976 and ends browsing, even if the source total is larger. Changing catalogs or active rows between requests can change page membership; this endpoint is not a frozen export.

Operation ID: `browseBrandProducts`. SDK methods: Python `browse_brand_products(brand, limit=24, offset=0)`; TypeScript `browseBrandProducts(brand, {limit: 24, offset: 0})`. The CLI command is `storerouter brands products <brand> --limit 24 --offset 0`.
