---
title: "Find similar brands"
description: "Rank brands by embedding similarity to source brand names."
---

`POST /brands/similar` rank brands by embedding similarity to source brand names.

Send `Authorization: Bearer <your-platform-api-key>` with every request. POST requests also require `Content-Type: application/json`. Use the base URL `https://api.storerouter.ai/v1`.

Send a JSON body with required `brands` (1–20 case-insensitive source names), `limit` (1–100, default 24), optional `facets`, and optional `exclusionFacets`. Unknown fields return `422`.

```json
{"brands":["Allbirds"],"limit":12}
```

The response contains `totalFound` and ranked `results`, using the [brand search response fields](/api-reference/search-brands). Returns `400` with `brands_have_no_embeddings` when none of the source brands have embeddings, and `503` with `brand_search_unavailable` when the search backend is unavailable.

See [Discover brands](/guides/brand-discovery) for brand-versus-store semantics, catalog scope, filter rules, MCP equivalents, and shared authorization, validation, and rate-limit errors.
