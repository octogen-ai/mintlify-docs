---
title: "Search brands"
description: "Discover brands from text and optional reference brands."
---

`POST /brands/search` discover brands from text and optional reference brands.

Send `Authorization: Bearer <your-platform-api-key>` with every request. POST requests also require `Content-Type: application/json`. Use the base URL `https://api.storerouter.ai/v1`.

Send a JSON body with required `text` (1–500 characters), optional `referenceBrands` (1–20 nonblank names, each at most 200 characters), optional `facets`, and `limit` (1–100, default 24). Unknown fields return `422`. Explicit facets override generated facets by name.

```json
{"text":"minimalist footwear","referenceBrands":["Allbirds"],"limit":12}
```

The response contains `totalFound` and ranked `results`. Each result includes `brandUuid`, `brandName`, `brandSlug`, `domain`, `brandDescription`, and `directorySubheading`. Metadata can be null. Returns `400` for `brand_query_unusable` or `brands_have_no_embeddings`, and `503` for `brand_search_unavailable`.

See [Discover brands](/guides/brand-discovery) for brand-versus-store semantics, catalog scope, filter rules, MCP equivalents, and shared authorization, validation, and rate-limit errors.
