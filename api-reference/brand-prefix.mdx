---
title: "Complete brand names"
description: "Find canonical brand names matching a prefix."
---

`GET /brands/prefix` find canonical brand names matching a prefix.

Send `Authorization: Bearer <your-platform-api-key>` with every request. POST requests also require `Content-Type: application/json`. Use the base URL `https://api.storerouter.ai/v1`.

Query parameters: required `prefix` (1–100 characters after trimming), and optional `limit` (1–50, default 20).

```http
GET https://api.storerouter.ai/v1/brands/prefix?prefix=all&limit=10
```

Returns a JSON array of canonical brand names. Matching includes raw and punctuation-free prefixes. Returns `503` with `brand_search_unavailable` when the search backend is unavailable.

See [Discover brands](/guides/brand-discovery) for brand-versus-store semantics, catalog scope, filter rules, MCP equivalents, and shared authorization, validation, and rate-limit errors.
