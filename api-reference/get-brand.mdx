---
title: "Get brand details"
description: "Resolve a brand slug or case-insensitive canonical name."
---

`GET /brands/{brand}` resolve a brand slug or case-insensitive canonical name.

Send `Authorization: Bearer <your-platform-api-key>` with every request. POST requests also require `Content-Type: application/json`. Use the base URL `https://api.storerouter.ai/v1`.

URL-encode `brand` as one path segment. Use a result's `brandSlug`, or `brandName` when the slug is null.

```http
GET https://api.storerouter.ai/v1/brands/allbirds
```

Returns `brandUuid`, `brandName`, `brandSlug`, `brandDescription`, `directorySubheading`, `domain`, `foundedYear`, `originCountry`, and `priceTier`. Fields other than the UUID and canonical name may be null. Internal assessments and research are omitted. An unknown brand returns `404` with `brand_not_found`.

See [Discover brands](/guides/brand-discovery) for brand-versus-store semantics, catalog scope, filter rules, MCP equivalents, and shared authorization, validation, and rate-limit errors.
