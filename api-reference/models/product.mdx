Use [`ProductSummary`](#productsummary) to display search results and [`ProductDetail`](#productdetail) for a full product record. Each entry in `ProductDetail.variants` is a [`ProductVariant`](#productvariant). The [compatibility table](#model-name-compatibility) maps each new name to its existing SDK import and OpenAPI component.

## ProductSummary

Search and More Like This return summaries in `items[]`. [Brand product browsing](/api-reference/browse-brand-products) returns them in `products[]`. See [Search products](/api-reference/search-products) and [More Like This](/api-reference/more-like-this).

| Field | Type | Description |
| --- | --- | --- |
| `uuid` | string, required | Identifier for the indexed product. Use it to deduplicate results across pages. |
| `productGroupUuid` | string or null | Parent group ID for a scoped result. A group uses its own `pg-` ID. |
| `selectedOptions` | object or null | Fixed merchant options on a scoped result. A group returns `{}`. |
| `availableOptions` | [`ProductAvailableOptions`](#scoped-available-options), optional | Display values and links from full indexed selections to `prd-` IDs. |
| `productUrl` | string, required | Merchant product URL. To read back a search result, pass its `uuid` to [Retrieve Product](/api-reference/retrieve-product). |
| `title` | string or null | Product title from the merchant. |
| `brand` | [`ProductBrand`](#productbrand) or null | Brand associated with the product. |
| `catalogKey` | string or null | Key of the catalog that supplied the product. |
| `catalogDisplayName` | string or null | Display name of the catalog that supplied the product. |
| `currentPrice` | number or null | Current selling price. |
| `originalPrice` | number or null | List or regular price, when available. |
| `currency` | string or null | ISO 4217 currency code, or null when unknown or mixed. |
| `primaryImage` | [`ProductImage`](#productimage) or null | The product's display image. |
| `images` | [`ProductImage[]`](#productimage) | Product images in display order. |
| `imageUrl` | string or null | Deprecated CDN URL. Read `primaryImage` for the image and its metadata. |
| `rating` | [`ProductRatingSummary`](#productratingsummary) or null | Aggregate customer rating. |
| `inStock` | boolean or null | Product-level availability. Read the individual variant for size- or color-specific stock. Null means unknown. |
| `isActive` | boolean | Whether the product is active in the index. |
| `colors` | string array or null | Product-level color labels. |
| `sizes` | string array or null | Product-level size labels. |
| `gender` | string or null | `male`, `female`, or `unisex`. Null when unknown or when several are listed. |
| `categoryPath` | string array or null | Taxonomy category path, starting at the root. |
| `displayMatchScore` | integer or null | Display score from 0 to 100, normalized for the current result set. |
| `rawScore` | number or null | Raw Elasticsearch hit score for debugging. |
| `updatedAt` | date-time string or null | When the index last updated the product record. |

### Scoped available options

For organizations with scoped product search and retrieve enabled, `ProductSummary` and `ProductDetail` can include `availableOptions`.

| Field | Type | Description |
| --- | --- | --- |
| `options` | Object of string arrays | Merchant display values by axis, such as `color`, `fit`, or `size`. A value may appear even when the matching units are out of stock. |
| `optionIndex` | Array of `ProductOptionLink` objects | Each row contains the look's full `selectedOptions` and its `productUuid`, a `prd-` ID. |

Compare every key and value in your selection with `selectedOptions` in a row. Key order can differ. Use `optionIndex` to find look links, and `options` to display choices. Sizes and other options can vary within a look.

#### Find and retrieve Black + Tall

This example uses illustrative IDs and a catalog group with separate indexed looks for Black + Regular and Black + Tall. A catalog that indexes looks by color alone may return a row for Black and list fit as a display value.

Send a search request for the product group.

```bash
curl -sS https://api.storerouter.ai/v1/products/search \
  -H "Authorization: Bearer $OCTOGEN_PLATFORM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"q":"crew neck sweater","understand":false}'
```

The search response includes the group and its look links. This excerpt focuses on the option fields.

```json
{
  "items": [
    {
      "uuid": "pg-aaaaaaaa-aaaa-4aaa-8aaa-aaaaaaaaaaaa",
      "productGroupUuid": "pg-aaaaaaaa-aaaa-4aaa-8aaa-aaaaaaaaaaaa",
      "selectedOptions": {},
      "availableOptions": {
        "options": {"color": ["Black"], "fit": ["Regular", "Tall"], "size": ["M", "L"]},
        "optionIndex": [
          {
            "selectedOptions": {"color": "Black", "fit": "Regular"},
            "productUuid": "prd-bbbbbbbb-bbbb-4bbb-8bbb-bbbbbbbbbbbb"
          },
          {
            "selectedOptions": {"color": "Black", "fit": "Tall"},
            "productUuid": "prd-cccccccc-cccc-4ccc-8ccc-cccccccccccc"
          }
        ]
      }
    }
  ]
}
```

Match `{"color":"Black","fit":"Tall"}` against the complete selection in the second row. Pass its `productUuid` unchanged to retrieve that look.

```bash
curl -sS https://api.storerouter.ai/v1/products/retrieve/prd-cccccccc-cccc-4ccc-8ccc-cccccccccccc \
  -H "Authorization: Bearer $OCTOGEN_PLATFORM_API_KEY"
```

The retrieve response identifies the same look and confirms its fixed selection. Read `product.variants` for the purchasable units within it.

```json
{
  "requestedUuid": "prd-cccccccc-cccc-4ccc-8ccc-cccccccccccc",
  "status": "found",
  "uuid": "prd-cccccccc-cccc-4ccc-8ccc-cccccccccccc",
  "product": {
    "uuid": "prd-cccccccc-cccc-4ccc-8ccc-cccccccccccc",
    "productGroupUuid": "pg-aaaaaaaa-aaaa-4aaa-8aaa-aaaaaaaaaaaa",
    "selectedOptions": {"color": "Black", "fit": "Tall"}
  }
}
```

## ProductDetail

Find the detail in `product` after [product lookup](/api-reference/lookup-product), single-product retrieval (`GET /products/retrieve/{uuid}`), or resolving from HTML (`POST /products/resolve-from-html`). Batch retrieval (`POST /products/retrieve`) returns it in `results[].product` for each product found.

`ProductDetail` shares most fields with [`ProductSummary`](#productsummary). The table below lists its different and additional fields. Summary fields `gender`, `categoryPath`, and `catalogDisplayName` appear only on `ProductSummary`. A detail response carries audience and categories in separate fields.

| Field | Type | Description |
| --- | --- | --- |
| `uuid` | string or null, required | Indexed product identifier. Null for an ephemeral lookup result. |
| `isActive` | boolean or null | Indexed product lifecycle state. Null for an ephemeral lookup result. |
| `description` | string or null | Product description from the merchant. |
| `inStock` | boolean or null | Product-level stock rollup. Null means unknown. |
| `sizes` | string array | Product-level size labels. Defaults to an empty array. |
| `colors` | [`ProductColor[]`](#productcolor) | Color labels and available swatch information. |
| `categories` | [`ProductCategory[]`](#productcategory) | Categories reported by the merchant. |
| `tags` | string array | Tags associated with the product. |
| `variants` | [`ProductVariant[]`](#productvariant) | Individual size, color, or SKU combinations. |
| `details` | [`ProductSpecifications`](#productspecifications) | Materials, fit, dimensions, and patterns. |
| `audience` | [`ProductAudience`](#productaudience) or null | Intended audience reported for the product. |
| `identifiers` | [`ProductIdentifiers`](#productidentifiers) | Merchant and catalog identifiers. |
| `breadcrumbs` | [`ProductBreadcrumb[]`](#productbreadcrumb) | Navigation trail on the merchant site. |
| `promotions` | [`ProductPromotion[]`](#productpromotion) | Promotions associated with the product. |
| `reviews` | [`ProductReview[]`](#productreview) | Individual customer reviews. |
| `videos` | [`ProductVideo[]`](#productvideo) | Product videos and thumbnails. |
| `availability` | string or null | Schema.org availability term for the product's own offer, such as `InStock` or `PreOrder`. |
| `itemCondition` | string or null | Schema.org offer condition, such as `NewCondition`. |
| `offerSku` | string or null | SKU on the product's own offer. |
| `languageCode` | string or null | Language of the title and description, such as `en-US`. |
| `additionalAttributes` | [`MerchantProvidedAttribute[]`](#merchantprovidedattribute) | Name/value pairs in the order supplied by the merchant. |
| `enrichment` | [`ProductEnrichment`](#productenrichment) or null | StoreRouter-generated classification and attributes. |

On-demand lookup can return images with the merchant URL only. Use `primaryImage.cdnUrl` when available and fall back to `primaryImage.url`.

## ProductVariant

One entry in `ProductDetail.variants[]`. All fields can be null when the merchant supplies no value.

| Field | Type | Description |
| --- | --- | --- |
| `sku` | string | The variant's own SKU. |
| `offerSku` | string | SKU on the variant's offer. |
| `gtin` | string | Variant barcode as published by the merchant. |
| `productUrl` | string | Merchant URL for this variant. |
| `color` | [`ProductColor`](#productcolor) | Color of the variant. |
| `size` | string | Size label for this variant. |
| `inStock` | boolean | Availability of this variant. Null means unknown. |
| `availability` | string | Schema.org offer term, such as `InStock`, `OutOfStock`, `PreOrder`, or `BackOrder`. |
| `currentPrice` | number | Current selling price for this variant. |
| `originalPrice` | number | List or regular price for this variant. |
| `currency` | string | ISO 4217 currency code for the variant's prices. |
| `imageUrl` | string | URL of the variant's image. |

## ProductImage

Both `primaryImage` and each entry in `images[]` use this shape.

| Field | Type | Description |
| --- | --- | --- |
| `url` | string, required | Original image URL on the merchant storefront. |
| `cdnUrl` | string or null | StoreRouter-hosted copy. Use this URL when available and fall back to `url`. |
| `width` | integer or null | Width of the hosted image in pixels. |
| `height` | integer or null | Height of the hosted image in pixels. |
| `sizeBytes` | integer or null | File size of the hosted image in bytes. |
| `mimeType` | string or null | MIME type of the hosted copy, such as `image/webp`. |

<CodeGroup>

```python Python
image = product.primary_image
src = (image.cdn_url or image.url) if image else None
```

```typescript TypeScript
const src = product.primaryImage?.cdnUrl ?? product.primaryImage?.url;
```

</CodeGroup>

## Supporting models

### ProductBrand

Brand displayed on a product. It contains a required `name` (string) and nullable string fields `slug`, `url`, and `description`. Use `slug` with the `brand_slug` facet.

### ProductRatingSummary

Product-level rating with `average` (number or null) and `count` (integer or null).

### ProductColor

Color data in `ProductDetail.colors[]` and `ProductVariant.color`. It contains a required `label` (string), plus `hexCode` and `swatchUrl` (strings or null).

### ProductCategory

One entry in `ProductDetail.categories[]`. It contains a required category `name` (string) and a merchant category `url` (string or null).

### ProductAudience

Target audience represented by `genders` and `ageGroups` (arrays of strings). Both default to empty arrays.

### ProductBreadcrumb

One entry in the merchant's navigation trail. It contains a required `name` (string) and a `url` (string or null).

### ProductPromotion

One merchant promotion. Its `promotionId`, `description`, and `code` fields are strings or null. A merchant may provide only a label in `promotionId`.

### ProductReview

One review with nullable `author` and `body` strings, `rating` (number), `ratingCount` (integer), `ratingType` (string, such as `Rating` or `AggregateRating`), and `publishedAt` (date-time string).

### ProductVideo

One video with nullable string fields `url`, `contentUrl`, `embedUrl`, `thumbnailUrl`, and `name`. The API uses `contentUrl`, then `embedUrl`, then the merchant's general URL to populate `url`.

### ProductSpecifications

Structured product details. It contains `materials`, `fit`, and `patterns` (arrays of strings) and `dimensions` (a free-form string or null).

### ProductIdentifiers

Merchant product `productId`, product-level barcode `gtin`, and merchant grouping ID `productGroupId`. Each field is a string or null.

### MerchantProvidedAttribute

One merchant-supplied name/value pair in `ProductDetail.additionalAttributes[]`. Each entry requires a `name` (string) and a `value` (string or number). A name can repeat when the merchant provides several values.

## Enrichment models

### ProductEnrichment

StoreRouter-generated data in `ProductDetail.enrichment`. It includes classification fields such as `type`, `gender`, `age_groups`, `color`, `color_family`, and `category_path`. The `canonical_brand` field carries normalized brand information. Use `attributes` for taxonomy values by name, `attribute_handles` for values by handle, and `structured_attributes` for each attribute's name, handle, and structured values.

### EnrichmentAttribute

One entry in `ProductEnrichment.structured_attributes[]`. It contains a required `name` (string), a required `handle` (string), and `values` (an array of [`EnrichmentAttributeValue`](#enrichmentattributevalue), empty by default).

### EnrichmentAttributeValue

One entry in `EnrichmentAttribute.values[]`. It contains a required display `name` (string) and a required taxonomy `handle` (string).

## SDK types

Import the model names from the SDK package. Python exposes snake_case attributes such as `product_url` and `primary_image`. TypeScript uses the JSON names, such as `productUrl` and `primaryImage`.

<CodeGroup>

```python Python
from octogen_ai_sdk import ProductDetail, ProductSummary, ProductVariant
```

```typescript TypeScript
import type { ProductDetail, ProductSummary, ProductVariant } from "@octogen-ai/sdk";
```

</CodeGroup>
