title: "Intro for developers"
---

For automatic agent setup, use [trial search](/authentication#automatic-trial-search).
It allows 50 searches per IP per UTC day without human signup. For full API access,
use a Developer organization and API key.


## What you can do

- **Search products** — query active crawled catalogs by keyword, filter by color, category, brand, price range, and other facets, and paginate through results.
- **Find similar products** — start from a product URL or UUID and return related items with optional relative price behavior.
- **Look up products by URL** — resolve a product page URL to a structured record with full detail: pricing, sizing, images, variants, and more.
- **Build AI agent workflows** — connect Claude Code, Codex CLI, or Claude Desktop directly to active crawled catalogs via the Developer MCP server.

<Note>
  Octogen is becoming StoreRouter. During the transition, API and MCP endpoints,
  SDK package names and CLI commands keep their existing names. The Platform
  remains available at its existing address. Your existing integrations continue
  to work.
</Note>

## Two ways to access StoreRouter

You can reach the same product data through two fully supported surfaces. Choose based on your runtime:

| Surface | Best for | Auth |
| --- | --- | --- |
| **REST API** | Backend services, batch jobs, server-to-server | Bearer API key (`octo_live_...`); WorkOS token for trial search |
| **MCP server** | Interactive AI agents (Claude Code, Codex, Claude Desktop) | OAuth 2.1 + PKCE |

Developer access covers active crawled catalogs. Private and merchant catalogs are excluded. Trial tokens work on REST search only.
